# GDPR Assessment

## Article 5(1)(c) — Data Minimisation

### Assessment

The organization collects several categories of personal data during customer registration.

Some information may not be necessary for all services or processing purposes.

However, no formal periodic procedure exists to review whether the personal data collected remains adequate, relevant and limited to what is necessary.

**Status:** Partially Compliant

### Identified Gaps

1. No formal procedure for periodically reviewing the necessity and relevance of collected personal data.
2. No documented process for identifying and removing data that is no longer necessary.

### Recommended Actions

1. Establish a formal periodic review of the personal data collected.
2. Document the purposes associated with each category of personal data.
3. Remove or stop collecting data that is not necessary for the relevant processing purpose.
4. Keep the data processing documentation updated following each review.

### Evidence

- Data minimisation review procedure
- Records of Processing Activities (ROPA)
- Documentation of periodic data reviews
